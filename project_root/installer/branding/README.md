# Installer identity

Original SORTH timetable mark, shared with `assets/sorth.svg` and `assets/sorth.ico`.
Generated from the existing `RECTS` geometry and navy/teal/violet palette, without
third-party images or fonts. Native wizard text remains selectable/localizable.

From `project_root`: `python -m tools.generate_installer_branding`.
`wizard.png` is 656×1256 (164:314); `mark.png` is 256×256 for high-DPI scaling.
Setup/uninstall use the multi-resolution ICO (16–256 px). No publisher-verification
or signing status is represented by this artwork.
