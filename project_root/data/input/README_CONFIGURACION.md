# Configuración de demostración

`Cursos_Ejemplo.xlsx` es la única entrada de demostración para la aplicación.
Contiene `Aulas` y `Cursos`, con encabezados en la primera fila. Cada fila de cursos
representa un grupo; las sesiones largas se dividen al planificar.

`demo_source.json` es la fuente de autoría del libro, no otro formato de importación.
Consulte [procedencia y regeneración](PROVENANCE.md) para sus cantidades y generación.
