# Soporte

## Preguntas y errores

El canal público es [GitHub Issues](https://github.com/RodrigoUC/SORTH-AI/issues). Busca primero si alguien reportó el mismo problema; utiliza la plantilla de error o propuesta para uno nuevo. También puedes abrir una consulta general.

Incluye versión o commit de SORTH, sistema operativo, origen del ejecutable o versión de Python, pasos mínimos, resultado esperado y resultado obtenido. Para fallos del planificador, incluye semilla y restricciones con datos ficticios. Para Excel, crea un archivo mínimo sintético que conserve el problema.

**Los issues y sus adjuntos son públicos.** No compartas planillas reales con datos personales, bases SQLite de sesión, tokens, correos privados ni capturas sin revisar. Si el caso contiene datos sensibles, no lo publiques.

## Seguridad

Una vulnerabilidad debe seguir [SECURITY.md](SECURITY.md), no un issue público con detalles de explotación.

## Alcance

El soporte es comunitario, sin plazo garantizado. Los artefactos de revisión de Actions son temporales y sin firma; no equivalen a una versión estable. Consulta las [limitaciones conocidas](docs/KNOWN_LIMITATIONS.md) y la [guía de distribución](project_root/WINDOWS_DISTRIBUTION.md).
